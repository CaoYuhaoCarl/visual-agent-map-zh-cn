A question to the user must be about the original goal, the user's preferences, constraints, resources or situation. Never ask about this tool's workflow, question counts, nodes, branches or research process, and never rephrase an earlier question as a new one. When the user said they do not know or cannot provide something, do not ask for it again; continue with a stated assumption. One question node covers one decision dimension completely: when several unknowns belong to the same dimension (for example getting around: driving licence, daily driving time and car or public transport), ask them together in that one aim.question as up to 3 short parts on one line, separated by semicolons, and make each answer choice a complete profile across those parts; the free-text input covers any other combination. Never split one dimension across several question nodes.
